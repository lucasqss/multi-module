# 07 — Documentos por finalidade

A lista de documentos é `[CONTRATO]` (Res. 285 art. 2º XIV-b) e/ou `[PRÁTICA]` da administradora. Esta matriz é o **ponto de partida**: valide-a com o regulamento dos grupos e com o Jurídico. Validades sugeridas ficam em `PAR-20`.

**Responsável:** C = consorciado · B = beneficiário · A = administradora · G = garantidor. **Obr.:** O = sempre · C = condicional.

## 1. Comuns a todas as finalidades

| Documento | Resp. | Obr. | Observação |
|---|---|---|---|
| Documento de identificação e CPF/CNPJ do consorciado | C | O | PJ: contrato social e documento dos representantes |
| Comprovante de residência | C | O | Validade sugerida: 90 dias |
| Comprovante de renda | C | O | Para a análise de capacidade (RN-05) |
| Estado civil / certidão de casamento ou união | C | C | Anuência do cônjuge na garantia, quando exigida |
| Dados da conta própria | C | C | Quando o consorciado recebe (sinal, sobra, espécie) |
| Aceite da comunicação formal | C | O | Gerado na confirmação (UC02) |
| Dados e conta do beneficiário | B | O | Qualificação (UC23) |

## 6. Eventos da cota

| Evento | Documentos |
|---|---|
| Cessão | Pedido do cedente; documentos e renda do cessionário; instrumento de cessão; anuência do garantidor (se o crédito já foi utilizado) |
| Sinistro | Certidão de óbito/laudo; documentos dos beneficiários; documento de representação (alvará, inventariante) |
| Espécie / crédito parcial / devolução da sobra | Dados da conta própria; termo de quitação (espécie e devolução) |
| Baixa de garantia | Termo de quitação da cota; termo de liberação |
